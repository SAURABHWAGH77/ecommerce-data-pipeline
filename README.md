# E-commerce Data Pipeline

## 📌 Project Overview

This project is a beginner-level ETL pipeline built using **Python and Pandas**.

The goal of the project is to process e-commerce data stored in multiple CSV files, clean and transform the data, combine the datasets, calculate revenue, and generate useful business insights.

The project helps practice real-world data engineering concepts such as:

* Data extraction
* Data cleaning
* Data transformation
* Data merging
* Data aggregation
* Data analysis
* Generating processed output files

## 📊 Input Data

The pipeline uses three CSV files.

### 1. customers.csv

Contains customer information.

Columns:

* `CustomerID`
* `Name`
* `City`
* `Age`

### 2. products.csv

Contains product information.

Columns:

* `ProductID`
* `ProductName`
* `Category`
* `Price`

### 3. orders.csv

Contains order transaction information.

Columns:

* `OrderID`
* `CustomerID`
* `ProductID`
* `Quantity`
* `OrderDate`

## 🧹 Data Cleaning

The project performs basic data-quality checks such as:

* Checking missing values
* Checking duplicate records
* Checking DataFrame shape
* Checking column names
* Checking data types
* Converting `OrderDate` to datetime format

Example:

```python
df_orders["OrderDate"] = pd.to_datetime(df_orders["OrderDate"])
```

---

## 🔗 Data Merging

The datasets are combined using Pandas `merge()`.

First, orders are merged with customers using:

```python
df_merged = pd.merge(
    df_orders,
    df_customers,
    on="CustomerID",
    how="inner"
)
```

Then products are merged:

```python
df_merged = pd.merge(
    df_merged,
    df_products,
    on="ProductID",
    how="inner"
)
```

This creates a single dataset containing customer, order, and product information.

---

## 💰 Revenue Calculation

Revenue is calculated using:

```text
Revenue = Quantity × Price
```

In Pandas:

```python
df_merged["Revenue"] = (
    df_merged["Quantity"] * df_merged["Price"]
)
```

## 📈 Business Questions

The pipeline answers the following questions:

1. Which customer generated the highest revenue?
2. Which city generated the highest revenue?
3. Which category generated the highest revenue?
4. What is the total revenue?
5. What is the average order value?
6. What is the total quantity sold for each product?
